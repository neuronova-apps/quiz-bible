Herramienta de recopilación RVR1960

Página auxiliar de desarrollo para organizar la extracción temporal por capítulo desde ApiBiblia. Esta página no almacena ni solicita la API Key; la ejecución real se realiza mediante GitHub Actions usando un secreto del repositorio.

Secreto requerido
APIBIBLIA_API_KEY debe agregarse en Settings → Secrets and variables → Actions.
Seguridad
La clave no se expone en esta página ni en JavaScript.

Flujo previsto

Elegir libro y capítulo.
Abrir GitHub Actions y ejecutar Extraer RVR1960 por capítulo con esos parámetros.
El workflow consulta ApiBiblia usando la API Key guardada como secreto.
El capítulo se mantiene únicamente en memoria durante el proceso.
Se genera un resultado normalizado para revisión y construcción del banco.
Al finalizar la ejecución no se conserva una copia temporal del capítulo en el repositorio.
Esta herramienta es de desarrollo. No coloque la API Key en este HTML, en JavaScript, en commits, Issues ni archivos públicos.
